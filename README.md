# Pulmono.AI

## Overview

Pulmono.AI is a Streamlit-based application for respiratory audio analysis. This project uses machine learning models to analyse respiratory recordings and generate predictions through an interactive web interface.

---

## Requirements

* Windows operating system
* Python 3.11 or later
* Internet connection (required only during the initial installation to download Python packages)

---

## Project Setup

The project includes an **`install_and_run.bat`** script that automatically:

* Creates a Python virtual environment (`.venv`) if one does not already exist.
* Installs all required Python packages listed in `requirements.txt`.
* Launches the Streamlit application.

No manual environment activation is required.

---

## Running the Application

1. Extract or clone the project folder.
2. Double-click **`install_and_run.bat`**.
3. Wait while the required packages are installed (this may take several minutes the first time).
4. Your default web browser will automatically open the Streamlit application.

For subsequent runs, simply double-click **`install_and_run.bat`** again.
